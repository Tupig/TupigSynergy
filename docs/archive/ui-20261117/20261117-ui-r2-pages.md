### Cross-page contract proposal

The page agent will remove vertical filler stretches/dummy bottom widgets, give cards a content-fitting vertical policy, use labeled one-column forms and preserve every functional object required by binding hooks. Lists will fit actual rows with a bounded cap and a <=one-row empty presentation; item/model changes invalidate geometry. Long paths/commands retain available width. The shared host should measure the current tab's own contents instead of QTabWidget's largest-tab sizeHint, put the existing button box directly after that content, and introduce scrolling only beyond the available screen height. Product pages will not set fixed window heights.

Action semantic boundary: Action::text currently serializes all recipients as `,*` or explicitly named recipients; it has no representation of the reference's “current computer” choice. Therefore the planned selector contains only All computers / Specified computers. Mouse actions retain the existing receiver-disabled behavior. This preserves the protocol contract.

Recording boundary: KeySequenceWidget exposes only keySequenceChanged, not recording state, and Escape currently passes through key capture. A small presentation-observation API (recordingChanged(bool), isRecording) is proposed so Save and status reflect real capture. The approved R2 spec now explicitly requires Escape to cancel and restore the sequence captured before recording; implement that behavior with synthetic Qt tests. Initialize the editor with the real KeySequence (not display text alone), and refresh the backup on each recording session.

### 跨页面接口建议

页面代理移除纵向填充stretch和占位widget，卡片按内容取高，使用有标签单列表单，保留hook所依赖的功能控件。列表按真实行数取高、有上限，空状态不超过一行；模型变化使布局失效。长路径和命令使用可用宽度。共享宿主按当前分页自身内容取高，不使用所有分页最大sizeHint，按钮接在内容后，仅超出屏幕可用高度才滚动。页面不设置固定窗口高度。

动作语义边界：Action::text只支持`,*`表示所有电脑，或显式指定名称，没有“当前电脑”表示；因此接收者下拉仅提供所有/指定。鼠标动作维持原不支持接收者选择的行为，不改协议。

录制边界：KeySequenceWidget当前只有keySequenceChanged，没有公开录制状态；Esc当前会进入捕获，不是取消。建议仅加recordingChanged(bool)/isRecording呈现观测接口，以真实状态控制保存和提示；现行R2主规格已明确批准Esc取消并恢复录制前组合；以合成Qt事件验证。编辑器须初始化真实KeySequence而非仅文字，每轮录制更新备份。
