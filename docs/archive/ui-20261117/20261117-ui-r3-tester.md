## English

Read-only findings and authority limits:

1. `synergy-gui.cpp` constructs QApplication, installs feedback and calls the real `onPreInit()` before parsing `--help`/`--version`; those flags are not safe bypasses. The real hooks call migration, scope preference, migration notice and TestSettings lookup. XDG isolates the main Settings/state stores, but not the literal `Settings::UserDir` overlay/legacy paths, NativeFormat legacy user/system stores, or entry SHM. The R2 no-hook/stub preview did not cover this entry.
2. `Settings::UserDir`/UserSettingFile/SystemSettingFile are inline static values derived from home/literal paths. QStandardPaths test mode cannot redirect these already-created QString paths. QSettings::setPath/test mode must not be assumed to isolate NativeFormat on macOS without exact backend verification. No HOME override is permissible.
3. Production entry owns a global QSharedMemory key and may connect to the global duplicate GUI socket. The MainWindow instance-socket seam alone does not isolate entry singleton handling. Both entry singleton and constructor listener need the same generated fixture identity before any attach/remove/listen operation.
4. The `/Volumes/` guard shows a message and returns 1, rather than proving a crash. PM reports that the currently mounted app is an older 2.1.6 dev artifact, so it is not evidence of the R2 user's actual failure. No new R3 production launch or DiagnosticReports scan was performed by this tester.
5. ButtonFeedback currently reacts to Enter/Leave/MousePress/MouseRelease with an 110ms low-opacity white overlay. It does not cover standard clicked/keyboard/accessibility activation, and a fast release restarts the animation from a low intermediate value. PageHost directly switches stack pages and has no transition animation. These are source-confirmed coverage/design gaps; actual visibility remains to be checked after an approved motion contract.

Startup contract C-R3-S01 / UI-013 / R3-V01:

- Compile the same production main source with every real hook into a test-only entry target. Only bootstrap context, phase observation and controlled quit differ. No skipped hook, symbol stub or replacement MainWindow. This executable is explicitly not byte-identical to the delivered default binary; audit the delivered binary/payload separately. The user's exact failing artifact remains unknown.
- Before QApplication, establish one fail-closed canonical temporary RuntimeContext routing user/system config, state, overlay, explicit legacy user/system inputs, migration backups/outputs, exact TestSettings and both SHM/socket identities. No home override, ancestor TestSettings fallback or daily-store access. Test dependency injection stays internal; no new production profile or Info.plist override feature.
- Required independent fixtures: fresh (empty old/new stores, real schema/notice creation); current (already migrated populated config, persisted values preserved); legacy (temporary INI old values, real mapping, backups, clear and notice). The INI source factory exercises the actual migration algorithm, not macOS NativeFormat/CFPreferences backend behavior. Source callsite/path receipts establish no daily reads; witness hashes alone prove only no writes.
- Migration applyMasterCompatDefaults() sets AutoStartCore=true. Record this real legacy result before a declared test-only phase callback disables auto-core/update before MainWindow. Preseeding false is insufficient. TestSettings, Desktop mode, empty enter/exit commands and temporary certificates cannot activate real runtime sharing. No permission grant, clipboard work, daily IPC probe or automatic network/core launch.
- Observe ordered real onPreInit, onMainWindow and onAppStart phases, first event-loop turn, real visible MainWindow/controller and exit0. Distinguish signal crash, nonzero normal exit, duplicate instance, loader failure and volume guard. Use distinct fixture IPC and a second owned fixture listener; invalid/missing context fails before hooks, and separate contexts do not contact each other. CUA owns native observation; headless results do not establish native launch acceptance.

Confirmed dangerous candidate: Action backend declares 11 valid types (0..10), but the UI has eight rows. Loading legal old mouse types 8..10 yields currentIndex -1; canSave(-1) is true and accept writes -1. `Action::text()` immediately indexes its name list without validation. This is a source-proven corruption/crash path candidate, not a reproduced user failure. Minimal presentation proposal: supported rows use stable data IDs; legal legacy or unknown IDs show one truthful stored-ID/name placeholder, disable Save and keep the entire original Action read-only, with Cancel preserving it. Do not offer implicit conversion by merely choosing another row. All GUI summaries must avoid unchecked Action::text on unknown IDs. Model formatting/export invalid-ID handling needs PE scope review: reject invalid configuration without truncating existing output or inventing a fallback protocol command; valid 0..10 encoding must remain unchanged.

Popup checks must use a real click/key selection, observe the actual popup view/menu and `activated/currentIndexChanged`, then verify committed model and reopen. Merely calling setCurrentIndex proves model wiring only. In Qt tests, include actual popup selection through the current real view and full press/release, Escape cancellation and clicked item semantic data. In native acceptance, inspect actual rows and selected value through CUA; if no selection occurs, retain it as a failure/unknown requiring diagnosis, not an automatic tool limitation. Menu styling and native-vs-Qt popup policy must be frozen before those checks; current source forces a QListView only for language, leaving other subpage popups with platform defaults.

Motion contract C-R3-A01 / UI-015 / R3-V04: page/tab/Back/option transitions visibly interpolate for about160ms, click feedback about110ms and end at the exact natural-fit geometry; mouse, keyboard and accessibility button activation give an observable short press pulse without delaying or duplicating the real action. Test actual intermediate rendered frames and controller/animation state, not just animation object existence. Include normal completion, rapid replacement, nested Back, resize, deletion/cancel during transition and explicit reduced-motion mode (immediate final state). A central policy reads supported native OS reduced-motion preference; unsupported preference detection is disclosed. Minimal seams are a deterministic policy override and inspectable completion/state, using actual production widgets and rendered frames. Overlay/snapshot layers must not intercept input, retain destroyed widgets, alter clipboard/key/core behavior or change Save/Cancel ownership. One action must route exactly once while feedback runs. Avoid asserting exact colors/frames before the approved design exists.

## 中文

只读结论与权威边界：

1. 生产 `main` 在解析帮助/版本参数前已创建QApplication、安装反馈并调用真实 `onPreInit`，所以帮助参数不是安全绕行入口。真实hooks会访问迁移、作用域、迁移提示和TestSettings。XDG只隔离主设置/状态，不覆盖硬编码UserDir的扩展/旧存储以及入口共享内存；R2去hook预览没有覆盖此入口。
2. UserDir等为静态QString，Qt标准路径测试模式不能重定向已构造的字面路径。不能未经精确后端验证就声称QSettings路径API隔离macOS NativeFormat；禁止覆盖HOME。
3. 入口全局共享内存和重复实例socket也须在首次操作前隔离，单靠MainWindow独立socket不够。使用独立随机IPC和独立witness，不触碰日常端点。
4. `/Volumes/`分支是显示提示后return1，并非崩溃证据。PM确认当前挂载app是旧2.1.6 dev，不能用它推断R2用户故障。本角色未执行新的R3启动或崩溃报告扫描。
5. 现有按钮反馈只对鼠标进入/离开/按下/释放做110ms低透明白层，标准点击/键盘/可访问性不覆盖，快速释放可能提前重启动画。PageHost直接切换栈，没有页面过渡。这是源码确认的设计/覆盖缺口，实际可见性须等冻结的动效契约后验证。

启动契约C-R3-S01 / UI-013 / R3-V01：使用同一生产main源码和全部真实hooks的测试专用入口，只改引导上下文、阶段观察和可控退出；明确不是交付二进制字节相同的启动测试，交付默认程序另审，用户实际故障入口仍未知。QApplication前一次性临时上下文覆盖用户/系统配置、状态、扩展、显式旧用户/系统源、迁移备份/输出、精确TestSettings及两个IPC身份，非法/缺失上下文在hooks前关闭失败；不增加生产profile或Info.plist覆盖功能。

必须覆盖fresh空存储、current已迁移存储、legacy真实映射/备份/清空/提示三组；旧源用临时INI注入并声明不是macOS NativeFormat后端验收。迁移会写AutoStartCore=true，先记录真实结果，再由声明的测试阶段回调在MainWindow前禁用自动core/更新，不能只预填false。观察全部hooks、首次事件循环、真实主窗口/控制器及exit0，区分崩溃、正常非零、重复实例、加载失败、卷守卫。路径收据/调用点审计用于证明无日常读取，哈希只能证明未写；不覆HOME、不读日常存储、不连日常IPC、不授权限、不共享。原生观察由CUA负责。

拟下拉契约 C-R3-M01/M02：动作显示ID[3,4,2,0,1,5,6,7]、方向[1,0,2,3]；关闭顺序隐藏true/退出false、系统语言显式空值；动作、方向、锁定、触发等均以itemData稳定语义ID加载/保存，不依赖视觉顺序；目标设备保持name数据。覆盖所有支持选项、实际相关字段、序列化命令、保存/取消/重开、语言切换和未知存储值；修饰键覆盖6个来源×7个目标及默认语义；首选项覆盖图标/启闭行为映射、日志规范数据、语言、网卡、证书位数。真实弹层选取须观察激活信号及保存重开，不用setCurrentIndex代替。原生AX若选取没有发生，应作为失败/未知继续定位，不能自动称工具限制。当前仅语言显式设置QListView，其余弹层沿平台默认，须在设计冻结后验证统一策略。

已确认危险候选：模型有11个合法动作类型，GUI仅8项；载入旧鼠标类型8..10会得到索引-1，canSave仍真、保存写-1，而Action::text无边界索引列表。它是源码已证的损坏/潜在崩溃路径，尚未证明就是用户本次故障。最小呈现建议：8个支持项使用稳定数据；旧版或未知ID明确显示原ID/名称的只读占位，整页禁用保存，取消保留原Action，不借选择其他行隐式转换。GUI摘要避免无检查格式化；模型格式化/导出遇非法ID须由PE定界，拒绝非法配置且不截断原文件，不伪造协议命令；合法0..10语义不变。

动效契约C-R3-A01 / UI-015 / R3-V04：页面/分页/选项/返回约160ms可见插值，按钮约110ms反馈，结束几何等于真实自然尺寸；鼠标、键盘、可访问性激活均有可见短按压反馈，真实动作不延迟、不重复。检查实际中间渲染帧和状态，覆盖快速替换、嵌套返回、缩放、删除/取消及减少动态效果立即结束；叠层不能拦截输入或保留已销毁页面，不改保存/取消/协议/共享含义。统一策略读取支持平台的原生减少动态设置，未支持检测须披露；最小测试缝为确定性策略覆盖及完成/状态观察，不替换真实组件。W1实际检查已获G4，产品仍等待检查充分性审核。
