## English

### Implementation evidence

- Preferences retain the existing radio-backed configuration and Save/Cancel/language-preview transactions. Two visible selectors bridge startup and close behavior; short selectors/spin fields and scope selector are 180px. Path and command fields retain available width.
- Computer settings reparent the original card widgets into four tabs. Validators, modifier values, corners, fixes and alias draft commit behavior remain unchanged.
- About displays the real application name in 22px type within 32px height, keeps the build-derived version and existing attribution/EULA/GPL hook, exposes project/contributor links and reads the bundled Lucide/Feather notice in a read-only child page.
- Fingerprint cards default to the complete real SHA-256 text, identify the algorithm and offer explicit user-initiated copying. Trust requires its explicit button; the rejection button remains the default. The image toggle is retained.
- Update cards use the existing downloader signals for bytes, speed, remaining time, verification and failure. The active button reads Cancel download; rejection destroys the downloader. The manual check page is indeterminate only while a real checker is active and cancels its callbacks before aborting. Verified download completion still waits for the separate Install Now click.
- Message cards retain plain-text handling for non-rich content and keep optional checkboxes inside the same card. Owned action icons use the shared offline helper; application branding icons remain application assets.

Files: `src/lib/gui/dialogs/{AboutDialog,AboutDialogDesign,ActionDialogDesign,ClientConfigDialogDesign,FingerprintDialog,HotkeyDialogDesign,ScreenSettingsDialogDesign,ServerConfigDialogDesign,SettingsDialog,SettingsDialogDesign}.{cpp,h}` where changed; `widgets/FingerprintPreview.{cpp,h}`, `widgets/MessagePage.{cpp,h}`, `update/UpdateDialog.cpp`, `mainwindow/MainWindowWindow.cpp`, and `translations/synergy_{zh_CN,ja}.ts`.

### Checks and limits

Fresh local static checks: clang-format on changed C++ files; `git diff --check` exit 0; both translation XML files parse successfully, including ten completed targeted new entries each. Remaining `QIcon::fromTheme` calls in the owned dialog files are application-branding icons only. The downloader, checker policy and platform installer implementation have no page-agent diff.

A narrow approved AppStyle selector preserves the 22px About heading against the generic dialog label rule.

The independent tester owns the unified native build, transactional/render regressions and safe CTest. Their actual evidence will determine runtime acceptance. No installed runtime, remote repository, system permission, real core connection or live clipboard was exercised by this page-agent verification. The new fingerprint copy action is intentionally not invoked by automated tests.

### 实现证据

- 首选项仍使用原有单选框绑定与保存/取消/语言预览事务；两个可见下拉框桥接启动和关闭行为。短下拉框、数值框及作用域框为180px，路径和命令框继续使用可用宽度。
- 电脑设置把原卡片控件移入四个分页，保持验证器、修饰键数值、死角、兼容修复及别名草稿提交行为。
- 关于页用22px字号和32px高度显示真实应用名，保留构建版本与原贡献者/EULA/GPL hook，提供项目和贡献者链接，并在只读子页读取随包的 Lucide/Feather 许可。
- 指纹卡默认显示完整真实 SHA-256 文本及算法名，提供仅由用户点击触发的复制动作。信任仍须明确点击；拒绝仍为默认按钮，图形切换保留。
- 更新卡片从原下载器信号取得字节数、速度、剩余时间、校验和失败状态。下载时按钮明确显示“取消下载”，拒绝页面会销毁下载器。手动检查页仅在真实检查器运行时显示不定进度，取消前先断开结果回调。校验完成后仍等待单独点击“立即安装”。
- 消息卡保留普通消息的纯文本策略，并把可选复选框放入同一卡片。范围内操作图标使用共享离线 helper，应用品牌图标保留原资源。

文件范围对应上文：dialogs 中已改的关于、动作、客户端、指纹、快捷键、电脑设置、服务端和首选项呈现文件，FingerprintPreview、MessagePage、UpdateDialog、获准的 MainWindowWindow 手动更新检查，以及中文/日文翻译。
